DSK AGENCY FUTURISTIC WEBSITE — VERSION 2

FILES
- index.html: website page
- style.css: responsive styling and futuristic motion effects
- Script.js: website features and scroll animations

HOW TO USE
1. Extract this ZIP to a folder.
2. Keep index.html, style.css, and Script.js together in the same folder.
3. Copy your original image files into that same folder if available: DSK.png, DS.jpeg, dsk.image.jpeg, image.png, image1.png.
4. Double-click index.html to preview in a browser.
5. To publish, upload these files and the image assets to your web hosting public folder.

MOTION INCLUDED
- Animated futuristic gradient background and hero orbital rings
- Floating/glowing logo and animated headline
- Scroll reveal transitions for sections and content throughout the page
- Hover lift, glow, and subtle 3D tilt on cards
- Animated call-to-action buttons and WhatsApp bubble
- Mobile responsive layout and reduced-motion accessibility support
